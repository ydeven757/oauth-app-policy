Privacy Policy

This application is a private, single-user automation tool. It accesses YouTube Data API data only for the developer's own YouTube channel, using OAuth credentials the developer controls directly.

  • No data is collected from, shared with, or sold to any third party.
  • No other users' data is accessed; the app authenticates only to the developer's own Google account.
  • Data retrieved (video metadata, upload status, analytics) is used solely to automate that channel's own upload/publishing workflow and is stored only on the developer's private infrastructure.
  • OAuth tokens are stored locally and never transmitted elsewhere.
